Seamless GitHub & CI/CD Integration

Drop a single YAML step into your GitHub Actions setup to enable distributed caching and instant status checks.

  • ✓ Zero setup overhead
  • ✓ Automatic pull request status comments
  • ✓ Smart delta execution (only test changed code)
name: Testoz Workflow
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: VocalPalsy/testoz-action@v1
        with:
          api-token: ${{ secrets.TESTOZ_TOKEN }}
